# Note
1. This plugin was written to help you understand how to use SQLiteLib.
2. SQLiteLibTest is an Intellij project file.
3. If you want to build this plugin from the source, you need to add SQLiteLib as a dependency module.
4. Put cat.jpg at the root of your server folder (where your server bukkit jar file is located).
5. Type /sqltest 1~4 to run test commands. I recommend running each commands in order.
